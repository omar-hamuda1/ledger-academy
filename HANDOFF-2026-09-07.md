## 1. What the project is

**Ledger Academy** — Arabic (RTL), dark-navy + gold e-learning platform teaching
**Business Administration (إدارة الأعمال)** to Egyptian secondary-school students
(3 grade levels). Lecturer/owner = "محمد حسين" (`ADMIN` role). Hard rule: the word
**"مدرس" must never appear in the UI** — use "محاضر" / "مدرب".

- **Stack**: Next.js 16 (App Router) + React 19 + TypeScript, Tailwind v4 (CSS
  `@theme`, no config file), Prisma v6 + Postgres on **Neon**, NextAuth v4
  (credentials, JWT, roles `ADMIN`/`STUDENT`), shadcn/ui remapped to navy/gold,
  framer-motion, Recharts, sonner.
- **~11,500 lines** of hand-written code (`src` 9.2k, `prisma` 0.4k, `tests` 0.9k).
- **No online payment.** Stripe was removed 2026-09-07 (no Egypt merchant
  support). Paid courses unlock via a **prepaid code** or an **admin-approved
  `CodeOrder`** (student uploads a payment-proof screenshot → admin approves →
  code auto-issued + enrollment created → student notified). Money moves manually
  (Vodafone Cash / InstaPay / bank / cash). `price` is a display figure in EGP.

### 4.1 End-to-end payment-proof smoke test on the live site  ← next task
This is the one flow that exercises the newly-added `AWS_*` + Upstash vars.

1. **Admin** (`instructor@example.com`): open `/dashboard/admin` — confirm charts
   render, notification bell doesn't error. Create a course with **price > 0**,
   publish it.
2. **Student** (`omar@gmail.com` or a throwaway): open that paid course → see the
   **"اطلب كودًا"** / `RequestAccessForm` (phone + payment note + **attach a
   screenshot image**, JPG/PNG ≤ 5 MB) → submit. Must succeed with an Arabic
   confirmation. **If it 503s → the `AWS_*` vars are wrong** (this is the real
   storage test).
3. **Admin** → `/dashboard/admin/code-orders` → the request is there with a
   **"عرض الإيصال"** link that opens the uploaded screenshot (1 h presigned URL) →
   click **موافقة (approve)**. A `PrepaidCode` is auto-issued + `Enrollment`
   created in one transaction; student is `notify()`d.
4. **Student** → bell dropdown shows the notification with the code → enter it in
   **"أدخل كود الكورس"** → course unlocks, lessons accessible.
5. Also sanity-check: `/dashboard/student` renders (rings, gamification widget,
   announcement banner if active), `/courses` + `/pricing` + `/` still fine.

Report where it breaks; the storage wiring lives in `src/lib/storage.ts` +
`src/app/api/uploads/payment-proof/route.ts` + `src/app/api/code-orders/*`.
