## 1. What the project is

**Ledger Academy** — Arabic (RTL), dark-navy + gold e-learning platform teaching
**Business Administration (إدارة الأعمال)** to Egyptian secondary-school students
(3 grade levels). Lecturer/owner = "محمد حسين" (`ADMIN` role). Hard rule: the word
**"مدرس" must never appear in the UI** — use "محاضر" / "مدرب".

- **Stack**: Next.js 16 (App Router) + React 19 + TypeScript, Tailwind v4 (CSS
  `@theme`, no config file), Prisma v6 + Postgres on **Neon**, NextAuth v4
  (credentials, JWT, roles `ADMIN`/`STUDENT`), shadcn/ui remapped to navy/gold,
  framer-motion, Recharts, sonner.
- **~11,500 lines** of hand-written code (`src` 9.2k, `prisma` 0.4k, `tests` 0.9k).
- **No online payment.** Stripe was removed 2026-09-07 (no Egypt merchant
  support). Paid courses unlock via a **prepaid code** or an **admin-approved
  `CodeOrder`** (student uploads a payment-proof screenshot → admin approves →
  code auto-issued + enrollment created → student notified). Money moves manually
  (Vodafone Cash / InstaPay / bank / cash). `price` is a display figure in EGP.
